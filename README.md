# Lesson 25 — The Invitation Problem 🎟️

Unit 3 · **граматичний урок «Relative Clauses with Prepositions»** + повторення 12 виразів уроку 24 · основний урок ≈29 хв + Game Zone 10–15 хв.

Продовження «The New Kid». Друзі планують суботу (скейт-парк, потім піца). Мія впевнена, що запросила Софі, — але надіслала запрошення в **старий** груповий чат. Софі записує Ітану голосове: вона почувається осторонь. Учні з’ясовують, що сталося, вчаться пояснювати це природною англійською (*the chat I sent your invitation **to*** / формально *the chat **to which** I sent…*), допомагають друзям помиритися і в breakout rooms планують ідеальну суботу, де ніхто не залишиться осторонь.

## Smart task distribution

- Обов’язкові завдання в кожному практичному блоці = **присутні учні × R**. 5 учнів → 5 + 5 + 5 + 5.
- Наступний — учень із найменшою кількістю відповідей у блоці, потім за весь урок; той самий учень **ніколи не отримує два завдання поспіль** (і між блоками теж).
- Завдання йдуть у порядку плану; додаткові учні отримують завдання з банку, без повторів.
- Зміна присутності будь-коли (👥 Class): виконане не зникає, решта перераховується. **Завершений блок не відкривається сам** — якщо хтось прийшов пізніше, під блоком з’являється «Reopen for them» або «+ Optional extra question» (не рахується).
- Під кожним завданням — *Student 2 of 5*, WHO’S NEXT, ✓ Mark completed, 🤝 With help, ↷ Next student, ⤼ Skip (черга зберігається), ↶ Undo. Відповідь ніколи не зараховується автоматично.

## Як провести

1. Відкрийте урок із платформи → кількість учнів → START LESSON.
2. Zoom: **📺 Focus** (F) — повний екран без учительських кнопок, або **🖥 Audience** — окреме чисте вікно для демонстрації (плеєр голосового там теж синхронізований). **Share sound** у Zoom — обов’язково для Епізоду 2.
3. Клавіші: → / пробіл — далі, ← — назад, **R** — відповідь (у граматиці друге R — пояснення), **H** — сховати, **I** — підказка, **D** — завдання виконано, **P** — play/pause голосового, N — епізоди, C — клас, W — нотатки, G — Game Zone.
4. **⚡ Quick** ховає необов’язкове (голосування «Which message?», follow-up, peer questions); жодне обов’язкове завдання учня не зникає.
5. Усе зберігається в браузері: перезавантаження нічого не скидає. Повне скидання — 🗺 Episodes → Restart (з підтвердженням).

## Live-режим (необов’язковий)

**📡 Live → Start live room** — код, посилання і QR. Телефони показують: прогноз, голосування (A/B повідомлення, яке повідомлення надіслати), чия черга (відповідь — лише після Reveal), свою команду й роль у breakout із карткою плану, квіз з особистими балами. Повідомлення вчителя підписані ключем — учень не може перемикати епізоди чи відкривати відповіді. Без Supabase сторінка чесно пише «this browser only».

## Звідки голос і картинки

- Голосове Софі — синтетичний голос (ШІ), точний текст із плану; позначене «AI voice». Свій запис (наприклад, учениці-волонтерки) — замініть файл.
- Окремих фото «Софі сама», «всі четверо в скейт-парку» і «субота в творчому просторі» поки немає, тому ці кадри зібрані з тих самих фото героїв поверх фонів (герої скрізь однакові). Хочете повноцінні реалістичні кадри — промпти в `img/PROMPTS.md`, далі файл у `img/scenes/` і рядок у `SCENE_PHOTOS`.
