# Як перезалити репозиторій

Тут лежить увесь курс у правильному вигляді. Файл уроку більше не називається
`index.html` — тепер це `lesson-05.html`, `lesson-13.html`, `lesson-14.html`.
Отже, залити урок у корінь і затерти платформу вже неможливо.

```
advanced-kids/
├── index.html                       платформа (єдиний index.html у проєкті)
├── .nojekyll
├── assets/watermark.png             спільний логотип для всіх уроків
└── lessons/
    ├── lesson-05/lesson-05.html  + img/ docs/ sql/ README.md SETUP.md
    ├── lesson-13/lesson-13.html  + img/ + 2 PDF-методички
    └── lesson-14/lesson-14.html  + img/ README.md
```

## Крок 1 — завантажити

1. Розпакуйте архів і відкрийте папку `advanced-kids`.
2. На сторінці репозиторію: **Add file → Upload files**.
3. Перетягніть **вміст** папки (`index.html`, `UPLOAD.md`, `assets`, `lessons`),
   а не саму папку.
4. Внизу напишіть `Уроки з новими іменами` → **Commit changes**.

> `.nojekyll` прихований на Mac і Windows. Якщо його не видно в списку — не страшно,
> він уже є в репозиторії з минулих разів.

## Крок 2 — видалити старі файли

Завантаження додає й замінює файли, але не видаляє. Старі `index.html` в папках уроків
залишаться зайвими копіями, тож їх варто прибрати. Для кожного: відкрити файл →
**⋯ → Delete file** → **Commit changes**.

- `lessons/lesson-05/index.html`
- `lessons/lesson-13/index.html`
- `lessons/lesson-14/index.html`
- `lessons/lesson-13/docs/1` — порожній файл, що лишився після створення папки
- `lessons/lesson-05/.nojekyll` — не потрібен у підпапці, він є в корені

Кореневий `index.html` **не чіпайте** — це платформа.

## Крок 3 — перевірити

Відкрийте `https://englishforkids.github.io/advanced-kids/` через **Ctrl+Shift+R**.

- Три картки: 14, 13, 5 — саме в такому порядку.
- **Open lesson** на кожній відкриває урок.
- Кнопка **←** в уроці повертає на платформу.
- Логотип — унизу по центру, в усіх трьох уроках.
- **Teacher guide** працює на картках уроків 5 і 13. В уроці 14 методичка вбудована
  в Teacher Mode, тому кнопки немає.

## Наступний урок

1. Папка `lessons/lesson-15/`, усередині `lesson-15.html` і `img/`.
2. У кореневому `index.html` дописати блок у список `LESSONS` (шаблон лежить
   там же в коментарі, з рядком `home : 'lesson-15.html'`).
3. Логотип в уроці брати з `../../assets/watermark.png`, кнопку `←` вести на `../../`.
