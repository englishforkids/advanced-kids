# Advanced Kids — структура курсу

Сайт: **https://englishforkids.github.io/advanced-kids/**

```
advanced-kids/
├── index.html                       платформа (єдиний index.html у проєкті)
├── UPLOAD.md  .nojekyll
├── assets/watermark.png             спільний логотип для всіх уроків
└── lessons/
    ├── lesson-05/lesson-05.html   The Night Everything Went Wrong
    ├── lesson-06/lesson-06.html   The Unlabelled Room
    ├── lesson-13/lesson-13.html   The Post That Disappeared
    ├── lesson-14/lesson-14.html   Likes Don't Equal Love
    └── lesson-15/lesson-15.html   If Only I Had Known…
```

Головне правило: **файл уроку ніколи не називається `index.html`**. Так його
неможливо випадково залити в корінь і затерти платформу.

У кожній папці уроку: сам `lesson-NN.html`, папка `img/`, за потреби `docs/`,
`audio/`, `README.md` і PDF-методичка.

---

## Як додати наступний урок

1. Папка `lessons/lesson-16/`, усередині `lesson-16.html` та `img/`.
2. На GitHub зайдіть **у папку `lessons`** → **Add file → Upload files** →
   перетягніть папку `lesson-16` цілком → **Commit changes**.
3. Відкрийте кореневий `index.html` → олівець ✏️ → знайдіть `const LESSONS = [`
   і допишіть блок після останнього уроку. Шаблон лежить там же в коментарі.
   Кома перед `{` обов'язкова.
4. **Commit changes** → через 1–2 хвилини **Ctrl+Shift+R** на сайті.

Урок з найбільшим номером платформа показує першим і в головній кнопці.

### Поля картки

| Поле | Що це |
|---|---|
| `n` | номер уроку — за ним іде сортування |
| `dir` | папка уроку, зі слешем у кінці |
| `home` | файл уроку всередині папки |
| `title` | назва історії |
| `grammar` | тема під назвою |
| `blurb` | 1–2 речення опису |
| `minutes` | тривалість, як показати на картці |
| `cover` | обкладинка, **відносно папки уроку** |
| `guide` | PDF-методичка, теж відносно папки уроку; рядок можна прибрати |
| `tags` | короткі мітки під описом |

## Що всередині уроку

- Кнопка **←** угорі зліва веде на `../../` — назад на платформу.
- Логотип береться з `../../assets/watermark.png` (не з папки уроку).
- Картинки — відносними шляхами: `img/cover.webp`.
- Live-режим: той самий проєкт Supabase у всіх уроках, ключі вже вписані
  в `window.LESSON_CONFIG` на початку файлу. Схема таблиць —
  `lessons/lesson-05/sql/schema.sql`. Кожен урок має свій канал, тому
  кімнати різних уроків не змішуються.

> Безкоштовний Supabase засинає після 7 днів без активності. Якщо між
> уроками пауза більше тижня — перевірте кімнату напередодні, а не за
> п'ять хвилин до заняття.

## Якщо щось пішло не так

| Симптом | Причина |
|---|---|
| Картка не з'явилася | Загублена кома перед `{` у списку `LESSONS` |
| Картка без обкладинки | Немає файлу за шляхом із поля `cover` |
| **Open lesson** → 404 | Файл лежить не за шляхом `dir` + `home` |
| В уроці немає картинок | Не залилася папка `img/` |
| Сайт відкривається уроком, а не платформою | У корінь залили файл уроку під іменем `index.html` — відновіть платформу з історії GitHub |
| Live room: `local only` | Урок відкрито з диска, а не з адреси GitHub Pages |
| Змінив файл, а на сайті старе | GitHub Pages оновлюється до хвилини, далі Ctrl+Shift+R |

Завантаження на GitHub **додає й замінює** файли, але ніколи не видаляє.
Якщо файл став непотрібним — відкрийте його → **⋯ → Delete file** → Commit.
