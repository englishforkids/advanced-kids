# Lesson 13 — як оновити на платформі

Це **перший сценарій уроку** (7 сцен, «The Post That Disappeared»), до якого додано:

- 🕵 **Детективи на уроці** — вписуєте імена учнів, завдання автоматично розподіляються між ними
  у п'яти сценах, з прогресом по кожному й перерозподілом невиконаного;
- 🎮 **Game Zone** — Alias, Quick Kahoot, Extra Challenge (поза прогресом справи).

Усе інше — сцени, тексти, картинки, Live room — як у першій версії.

## 1 · Залити папку

GitHub → `advanced-kids/lessons/` → **Add file → Upload files** → перетягніть папку
`lesson-13` з архіву → Commit. Вона перезапише `index.html` та `img/`.

> Якщо у вашій поточній папці `img/` лежить `watermark.png` — залиште його, в архіві його немає.

## 2 · Картка на платформі (лише якщо уроку ще немає на хабі)

У кореневому `index.html`, у масиві `const LESSONS = [`:

```js
  ,{
    n       : 13,
    dir     : 'lessons/lesson-13/',
    title   : 'The Post That Disappeared',
    grammar : 'Revision 11–12 · Causative structures',
    blurb   : 'Алекс виклав фото з вечірки й видалив його через десять хвилин. Детективи збирають докази, відновлюють хронологію і пишуть чесний допис.',
    minutes : '30–60 хв + Game Zone',
    cover   : 'img/cover.webp',
    tags    : ['Live room', 'Revision', 'Story quest']
  }
```

## 3 · Перевірити після публікації

1. Відкрити урок із платформи, **Ctrl+Shift+R**.
2. **🕵** → вписати 4–6 імен → у сценах Decode / Read / Grammar / Interview / Optional
   має з'явитися смужка з іменами й номерами завдань.
3. Клікнути по імені у смужці — підсвічуються саме його завдання.
4. Виконати частину завдань → біля імен `✓`; видалити учня → **🔁** переносить лише невиконане.
5. **🎮 Game Zone** → Alias (випадкове слово, таймер, 👤 Наступний), Quick Kahoot, Extra Challenge,
   **← Назад до справи** повертає на Final Reveal.
6. **📡 Connect** → Start live room → відкрити посилання на телефоні.
