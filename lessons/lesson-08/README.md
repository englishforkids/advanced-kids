# Lesson 8 — The Message That Was Never Sent (Modal Verbs in the Past)

18:50. До дедлайну конкурсу **Creative Voices Challenge** — десять хвилин, а відео команди
«Your Inner Critic Is Wrong» зникло зі спільної папки. У груповому чаті з’являється повідомлення від Unknown:
*“I’m sorry. I shouldn’t have done that. I thought I was helping.”* — і через 5 секунд зникає.
Учні — цифрові детективи: повторюють 12 виразів уроку 7, на дошці доказів відкривають модальні дієслова в минулому,
слухають три голосові, будують версію, у breakout rooms пишуть детективний звіт — і нарешті знаходять відео.

```
lessons/lesson-08/
├── lesson-08.html      увесь урок (один файл, vanilla JS, без збірки)
├── img/mia.webp        Мія   (ті самі фото, що в уроці 7)
├── img/leo.webp        Лео
├── img/alex.webp       Алекс
├── img/words/*.webp    12 ілюстрацій до слів уроку 7
├── img/cover.webp      обкладинка картки на платформі
└── audio/              (необов’язково) mia.mp3, leo.mp3, alex.mp3 — справжні записи голосових
```

## Що бачать учні

- Угорі — **7 сцен історії**: 🎬 The Missing Video → 🧠 Words from Yesterday → 🗂️ The First Clues → 🎙️ The Voice Messages →
  🕵️ What Really Happened? → 📝 The Final Report → ✅ The Truth. Пройдені сцени стають зеленими.
- **Годинник історії** (⏳ 18:50 → 18:55) відлічує хвилини до дедлайну 19:00; наприкінці — «video submitted ✓».
- **🗂 Clues** (E) — case file: 6 доказів «вилітають» на екран, коли їх знаходять. **⭐** — бали детектива
  (доказ, правильний висновок, прослухані голосові, готовий звіт). Неправильна відповідь бал не забирає — лише підбадьорення.
- Усе відкривається поступово: повідомлення друкуються, правило — тільки після відповіді на discovery-питання.
- **UA** (U) — український переклад інструкцій, питань, граматики, слів і складних реплік. За замовчуванням прихований.
- Приклади в граматиці навмисно без імені винуватця — розгадка відкривається лише після голосових.

## Маршрут (Core ≈ 31 хв · Full ≈ 35 хв + «Show all 12 words» ≈ 2 хв)

| Сцена | Екрани | хв |
|---|---|---|
| 🎬 The Missing Video | титул і герої → груповий чат 18:50 (повідомлення Unknown зникає) + MISSION STARTED → 3 питання розминки → голосування «What should we check first?» | 3,5 |
| 🧠 Words from Yesterday | паніка в чаті → 6 карток слів (+ Show all 12) · Quick challenge, 5 речень *(optional)* → NEW CLUE: FILE ACTIVITY LOG | 3–4,5 |
| 🗂️ The First Clues | дошка доказів: 6 доказів = 6 тем (A regret · B possibility · C certainty · D negative deduction · E might not / shouldn’t / needn’t have · F continuous) → Grammar challenge (3) · Extra practice (3) *(optional)* | 7–8,5 |
| 🎙️ The Voice Messages | 3 голосові (Mia, Leo, Alex) → 3 питання · Think about Alex *(optional)* → INVESTIGATION UPDATE | 5–6,5 |
| 🕵️ What Really Happened? | дошка версій: головне питання + підказки-питання → 4 follow-up питання | 4 |
| 📝 The Final Report | місія від організаторів + приклад → Report builder + таймер 3:00 → презентації команд | 6 |
| ✅ The Truth | пошук по диску → FILE FOUND → фінальний чат → PROJECT RECOVERED → рефлексія → граматичний підсумок | 2 |

**🧭 Core route** (у Teacher Mode) ховає всі optional-екрани одним кліком. Кнопка **⏭ Skip** з’являється сама, коли наступний екран необов’язковий
(після Grammar challenge вона називається **Skip extra grammar practice**).

## Як провести урок

1. Відкрийте урок із платформи й поділіться екраном у Zoom (**✔ Share sound** — для голосових).
2. **Continue** (→ / пробіл) — наступне повідомлення / питання / доказ; **Back** (←) — назад.
3. **Check answer / Show answer** (A) — відкрити і знову сховати відповідь. **Hint** (H) — підказка або початки речень.
   Учні відповідають усно — клікайте їхній варіант, потім Check answer.
4. **🧑‍🏫 Teacher** (T): що сказати англійською, нотатки українською, відповіді, підказки для тихих учнів, додаткові питання,
   годинник уроку, **↺ Reset activity**, UA, граматика, таймер, позначення сцен, перехід до будь-якого екрана, **Restart lesson** (з підтвердженням).
5. **🗺️ Story map** (M) — 7 сцен-вузлів і список усіх екранів із хвилинами. **📘 Grammar** (G) — довідка з усіх 8 форм.
6. **🖥 Present** (P) — режим показу: більший текст і повний екран.
7. Голосові: якщо в папці `audio/` є `mia.mp3`, `leo.mp3`, `alex.mp3`, урок грає записи з їхньою справжньою тривалістю.
   Інакше читає голос браузера (на картці написано *synthesized voice*; тривалість з’являється після першого прослуховування). Транскрипти — кнопкою.
8. Breakout: на екрані Mission — **📋 Copy mission for Zoom chat**; на Report builder оберіть кількість команд (1–4) і **Start 3:00** (±1 хв).
   Таймер видно на всіх екранах (⏱ угорі), наприкінці дзвінок.
9. Презентації: **🎤 Present** показує речення команди великим шрифтом, потім **Team complete**.

## Live-режим для телефонів (необов’язковий)

**📡 Live → Start live room** — 6-значний код, посилання і QR. Учні заходять без акаунта, лише з ніком.
На телефонах: голосування (хто написав повідомлення, що перевірити, discovery-питання, граматика, аудіювання), короткі відповіді
(розминка, версія, follow-up, рефлексія), спільний звіт команди (ім’я + закінчення речення, кнопка «Send report to the teacher»), реакції під час виступів.
Учні завжди на тому ж екрані, що й учитель, — самі вперед не переходять. **🔒 Lock answers** (у віконці Live або в Teacher Mode) закриває відповіді.
На сервері нічого не зберігається (`SAVE_ANSWERS: false`), відповіді живуть лише в браузері вчителя й зникають після **Restart lesson**.
Supabase — той самий проєкт, що в уроках 5, 13–18 (`window.LESSON_CONFIG` на початку файлу). Без інтернету / Supabase урок повністю працює через демонстрацію екрана.
