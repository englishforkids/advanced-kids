# Lesson 15 — If Only I Had Known… (Mixed Conditionals) · Advanced Kids 2.0

Student-led · story-driven · practice-first. Mia finds an old post, **the timeline is broken**,
students repair it (TIMELINE RESTORED 15 → 35 → 65 → 80 → 100%).

```

├── img/mia.webp, leo.webp  character photos
├── img/old-post.webp       Mia's old #DanceChallenge post
├── img/feed/post-1…5.webp  Mia's Feed posts
└── img/cover.webp          hub card cover
```

## Routes
- **CORE ≈ 29 min** (5 students) · **EXTENDED ≈ 35 min** (+ Mia's notes, Build the story, Fix the timeline).
  The 🛣️ Core / Extended button switches. Times grow with class size and Round 2.
- **Game Zone** after the core lesson: Kahoot (10 questions, copy for Kahoot), Alias (in-lesson cards +
  the course Alias game), Word bank. It never changes the lesson route.

## Interface
- **Focus Mode** (default): one task per screen. Bottom bar: Back · Hint · Reveal · Answer · Skip · Reset · CCQ · ICQ · Next.
- **Hybrid Workspace** (🧰, key W) — teacher-only drawer: Notes (steps, answers, mistakes, timing, CCQ/ICQ),
  Students, Words (vocabulary bank EN + UA), Grammar map, Story, Progress, Games.
- **Students today: − 5 +** in the top bar (1–12). Changing it never resets finished work —
  only open turns are redistributed.

## Smart task distribution (N × rounds)
Vocabulary (Mia's Feed, 24-item bank, 5 task types), Listening questions (12), Repair the timeline (24),
Speaking (24 questions): every student/pair/team gets one turn per round; Round 2 is optional.
Turn card: ✓ Next student · ⏭ Skip student · 🔀 Shuffle order. Modes per section: Solo / Pairs / Teams.
Names can be entered in Workspace → Students.

## Timer
⏱ in the top bar: 30 s · 1 · 2 · 3 · 5 min, Start / Pause / Reset / Hide. It never moves the lesson on.

## Live Student Mode (optional)
📡 Live → room code / link / QR. Phones vote (A/B/C, polls, Kahoot), react with emoji, send team work
and final-challenge answers. The lesson works fully without phones.

## Keys
→ / ← · H hint · R reveal · A answer · E example · S skip · W workspace · T notes · M map · F full screen · + / − students
