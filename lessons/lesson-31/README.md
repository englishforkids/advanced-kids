# Lesson 31 — My Hobby Went Viral! 📱

Unit 4 · **My Weird Obsession** (лексичний урок, без граматики) · 10 виразів про хобі й незвичні таланти · основний урок **29 хв** + Game Zone 10–15 хв.
Концепція **Advanced Kids 2.0 — student-led, story-driven, practice-first**: один екран — одне завдання, учні читають, вирішують і говорять, учитель лише веде.

Лео (15) потай будує крихітні міста з картону. Майя вмовляє його зняти відео — і наступного ранку в нього 248 000 переглядів. Потім приходять коментарі: добрі… і не дуже. Учні вирішують, що Лео робити далі, говорять про власні захоплення й вигадують ідею вірусного відео.

## Структура (≈29 хв)

| Розділ | Що відбувається | хв |
|---|---|---|
| 0 · Lobby / Setup | кількість учнів, імена, Workspace / Focus, Live room | — |
| Episode 1 · The Secret Hobby | заставка → «Meet Leo» (учень читає по рядку) → warm-up (кожен учень — своє питання) → прогноз | 3 |
| Episode 2 · The Viral Video | чат Майї й Лео за ролями → **відео учнів** (прогноз-голосування → перегляд → реакція) → «The next morning…» (анімовані цифри) → **5 повідомлень × 2 вирази** (Guess / Reveal / UA / Example) → **Which phrase fits?** | 7 |
| Episode 3 · The Comment Storm | коментарі по одному → текст «Famous Overnight» (3 частини, 3 читачі) → питання (відповіді приховані) → **рішення A / B / C** → продовження за вибором класу | 6 |
| Episode 4 · Your Obsession | учень обирає картку (номер або 🎲), відповідає, інший учень ставить follow-up | 6 |
| Final Mission · Make It Go Viral! | брифінг (учні читають 3 елементи) → breakout (Solo / Pairs / Teams, таймер 3:00) → презентації по черзі + реакція класу | 7 |
| Story Ending | повідомлення Лео → рефлексія → фінальний екран | ~1 |
| 🎮 Game Zone | Alias + таблиця всіх 10 виразів · банк 10 питань для Kahoot · Guess the Obsession | 10–15 |

**Три продовження** (Episode 3) — жодне не «поразка»: A — Лео будує лише для себе, Майя це поважає; B — ділиться, коли готовий; C — нове відео «Why I build», не сперечається з хейтерами. Усі гілки сходяться в одну фразу й ведуть до Episode 4.

## Як провести

1. Відкрийте урок із платформи → у Lobby задайте кількість учнів та імена → **START LESSON** → **▶ START STORY** (запускає годинник уроку).
2. Zoom: **🖥 Audience** — окреме «чисте» вікно (без нотаток, відповідей і кнопок учителя) — його й показуйте; у своєму вікні тримайте 🧑‍🏫 Teacher. Або **📺 Focus** (F) в одному вікні.
3. **Відео:** звук іде з вікна вчителя, вікно Audience показує картинку без звуку (щоб не було луни). У Zoom увімкніть **Share sound**.
4. **Next** (→ / пробіл / пульт) відкриває наступне повідомлення, рядок або наступного учня. **Back** (←) — крок назад, нічого не стирається.
5. Клавіші: **R** reveal · **H** hide · **I** hint · **D** хід виконано · **F** Focus · **T** панель учителя · **C** клас · **G** Game Zone · **Esc** закрити.
6. Усе зберігається в браузері: оновлення сторінки нічого не скидає. Почати заново — 🏠 Lobby → Restart (з підтвердженням).

## Розподіл ходів (N × R)

- Warm-up, Which phrase fits?, Your Obsession — по одному ходу на учня (5 учнів → 5 ходів); для 6+ учнів з’являються рівноцінні варіанти питань, а не повтори.
- Vocabulary — 5 карток: один учень читає й вгадує, інший дає власний приклад (5 учнів → по 2 вирази на учня). Для 3–4 учнів картки розподіляються автоматично.
- Episode 3 — 3 читачі тексту + 3–6 питань, щоб кожен мав хоча б один внесок.
- Наступний — присутній учень, у якого найменше ходів; клік по імені — передати хід іншому, ↷ Pass — запитати іншого, ＋ Extra turn — додатковий (необов’язковий) хід.
- Зміна кількості учнів перерозподіляє лише невиконані ходи; виконані (✓) не зникають. Таймер ніколи не пропускає хід учня автоматично.

## Live Classroom (необов’язково)

**📡 Live → Start live room** — код, посилання, QR. Учні заходять з телефона з нікнеймом (без акаунтів), бачать поточне завдання й чий хід, голосують (вірусне відео, рішення Лео, реакція на презентації), надсилають короткі відповіді (ідея команди, рефлексія) і реакції-емодзі. Учитель бачить усе в реальному часі (віконце внизу ліворуч), а відповіді на екрані з’являються лише після кнопки 📱 Show phone answers.
Технічно: Supabase Realtime (broadcast + presence) того ж проєкту, що й інші уроки, лише публічний ключ, таблиці не потрібні. Повідомлення вчителя підписані (ECDSA) — учень не може перемикати сцени чи бачити відповіді до Reveal. Якщо Supabase недоступний, урок чесно показує **LOCAL DEMO** (лише вкладки цього браузера), а весь урок працює через показ екрана.
