# Lesson 13 — Revision (Lessons 11–12)

**🕵️ The Post That Disappeared** · Advanced Kids, 11–15 років · 35 хв матеріалу / до 60 хв заняття

Інтерактивний урок-розслідування для живого заняття в Zoom. Алекс виклав фото зі шкільної
вечірки — і за десять хвилин видалив. Кожне завдання відкриває новий доказ.

Повторюємо: 12 виразів про соцмережі · causative structures
(`have/get + object + V3`, `have + person + V`, `get + person + to + V`, `make + person + V`).

Повний сценарій для вчителя (45 с., скриншоти, фрази EN/UA, усі відповіді, екрани учнів): [`docs/teacher-guide.pdf`](docs/teacher-guide.pdf)  
Коротка версія (8 с.): [`docs/teacher-guide-short.pdf`](docs/teacher-guide-short.pdf)

## Сцени

1. Mission Start — warm-up голосування
2. Decode the Feed — matching 12 / 6 виразів
3. Read the Evidence — текст «The Perfect Night?» + 5 питань
4. Grammar Investigation — 3 картки правил + 5 вправ
5. Interview the Detectives — 5 карток для говоріння
6. Breakout Mission — командний проєкт «новий чесний допис»
7. Final Reveal — голосування + exit ticket
\+ Optional Challenge — Fix the Influencer's Story

`.../lessons/lesson-13/?room=1234&role=student`.
