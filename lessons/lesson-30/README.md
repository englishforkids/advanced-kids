# Lesson 30 — What If...? The Friendship Multiverse 🌀

Unit 3 · **Unit Revision (Lessons 21–29)** · 33 вирази Unit 3 + **emphatic do / does / did**, **relative clauses with prepositions**, **cleft sentences** · основний урок **30 хв** (Extended ≈ 40 хв) + Game Zone 10–15 хв.
Концепція **Advanced Kids 2.0 — student-led, story-driven, practice-first**: один екран — одне завдання, учні читають, вирішують і говорять, учитель лише веде.

Четверо друзів планували суботу. Ітан не отримав відповіді й вирішив, що його не хочуть бачити. Ной поширив обрізаний скриншот повідомлення Лілі — і всі подумали, що вона хотіла виключити Ітана. Друзі посварилися, зустріч не відбулася. Учні — **MULTIVERSE TEAM**: досліджують три альтернативні таймлайни, знаходять помилки, «ремонтують» граматику, обирають майбутнє, у breakout складають план із трьох кроків — і їхній вибір визначає фінал.

## 7 актів (≈30 хв)

| Акт | Що відбувається | хв |
|---|---|---|
| I 🌀 The Portal Opens | системне повідомлення рядок за рядком → місія → «Can one small choice change a friendship?» | 2 |
| II 📡 Friendship Radar | 4 ситуації → правильний вираз (відповідь показує вчитель) → RADAR ACTIVATED | 3 |
| III 💬 The Broken Timeline | 3 всесвіти: чат по одному повідомленню (кожен читає свого героя) → питання на розуміння → рішення з наслідками → підказка-clue | 6 |
| IV 🛠 Rewrite Reality | 3 граматичні портали × 2 питання (emphatic do · relative + preposition · cleft) | 6 |
| V 🔮 Choose the Future | три майбутні (A/B/C) з прев’ю, ★ вибір класу → 2 питання для мовлення | 3 |
| VI 🤝 Create the Best Timeline | місія → breakout (таймер 4:00, картки команд) → презентації, ★ найкращі ідеї | 7 |
| VII ✨ The Final Reveal | Universe 04 → фінальна розмова → рефлексія → фінальний екран із досягненнями | 3 |
| 🎮 Game Zone | Alias (посилання / вбудовування), Word Bank (33 вирази), Lightning round | після уроку |

**Три фінали** залежать від вибору класу в акті V: **B → Best Timeline Restored**, **C → A New Beginning** (дати одне одному час), **A → Different Paths** (не всі дружби тривають, але повага лишається). Учитель може змінити фінал (кнопки бачить лише він).

**Extended** (⏳ у верхній панелі або в Teacher Setup) додає: пари «what’s the difference?» (fall out / drift apart тощо), обговорення після кожного всесвіту, ще одне граматичне питання й мовлення в кожному порталі, третє питання в акті V, 90 с на презентацію.

## Як провести

1. Відкрийте урок із платформи → **⚙️ Teacher Setup**: кількість учнів (3–6, + extra), імена, Core / Extended → **ENTER THE MULTIVERSE**.
2. Zoom: **📺 Focus** (F) — ховає все вчительське, або **🖥 Audience** — окреме чисте вікно (його й показуйте), а у своєму вікні тримайте 🧑‍🏫 Dashboard.
3. **Next** (→ / пробіл) відкриває наступне повідомлення / рядок; на питанні — спершу перевіряє вибрану відповідь. **Back** (←) — крок назад.
4. Клавіші: **R** показати відповідь · **H** сховати · **I** підказка · **D** хід виконано · **M** карта таймлайнів · **B** Word Bank · **G** Game Zone · **T** Dashboard · **C** клас · **F** Focus · **Esc** закрити.
5. Усе зберігається в браузері: оновлення сторінки нічого не скидає. Почати заново — 🏠 Start screen → ENTER (з підтвердженням) або ⟲ Reset lesson у Dashboard.

## Teacher Dashboard (🧑‍🏫)

- **Lesson** — поточний акт і крок, Prev/Next, перехід до будь-якого кроку, Reveal / Hide / Hint / Reveal all messages, ключ відповіді; аварійні кнопки: Skip optional task, Jump to Breakout, Jump to Final Reveal, Resume previous scene; вибір фіналу; Focus / Audience / анімації / Reset.
- **Notes** — мета й «як провести» для кожного екрана (англ. + укр.), ключ, власні нотатки.
- **Class & turns** — кількість, імена, присутність, ⏸ тимчасовий пропуск, +1 участь, лічильник ходів, «Next student», скидання розподілу, план розподілу по блоках.
- **Time** — таймер уроку (/30 або /40), таймер акту з рекомендованою тривалістю, breakout-таймер (пресети 1/4/5/6 хв, +1 хв). Нічого не перемикається автоматично.
- **Resources** — Word Bank, Grammar cheat sheet, Game Zone, Live, модельні відповіді (згорнуті), follow-up питання, клавіші.

## Smart turns

- Наступний — присутній учень із найменшою кількістю ходів; при нічиїй — по колу, тож блоки починаються з різних учнів. 5 учнів → у Core кожен отримує ≈7 ходів.
- Читання: кожному героєві сцени — свій учень (чип 🎙 біля репліки; клік — інший учень). Якщо учнів менше, ніж героїв, хтось читає дві ролі.
- Футер: **✓ Done** · **↷ Pass** (запитати іншого — хід не зараховується) · **＋ Another** (ще один учень відповідає).
- Хід зараховується, коли вчитель іде далі. Учні ніколи не мусять говорити про себе — можна відповідати про героїв.

## Live Classroom (необов’язково)

**📡 Live → Start live room** — код, посилання, QR (той самий Supabase Realtime, що й в інших уроках; лише broadcast + presence, таблиці не потрібні). Телефони бачать свою роль у читанні й свою чергу, відповідають на питання та голосування (учитель бачить кількість), а в breakout редагують **лише картку своєї команди**. Повідомлення вчителя підписані (ECDSA): учень не може перемикати сцени, бачити відповіді до Reveal чи обирати фінал. Без Supabase кнопка Join неактивна, а урок повністю працює в режимі показу екрана.
