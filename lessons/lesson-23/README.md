# Lesson 23 — The Last Hangout 🌆

Unit 3 · **повторення уроків 21–22**: 11 виразів про дружбу + **emphatic DO / DOES / DID** · основний урок 30 хв + Game Zone.

Алекс переїжджає в суботу й кличе друзів на останній вечір на даху. Але компанія змінилась: Алекс і Мія віддалились, Лео жартує, коли ніяково, Софі тримає всіх разом, а Ной почувається третім зайвим. Учні — **Friendship Crew**: читають груповий чат, слухають голосове Алекса, мирять героїв, у breakout rooms рятують вечір і обирають один із трьох фіналів.

## 6 сцен (30 хв)

| Сцена | Що відбувається | хв |
|---|---|---|
| 1 · The Invitation | Friendship Crew (присутність) → титул → груповий чат THE OG SQUAD 🔥 (кожне повідомлення читає інший учень) → *прогноз (opt)* → **DECODE THE FRIEND GROUP**: 2 раунди × N учнів → spill the tea | 4 |
| 2 · The Voice Note | Софі пересилає голосове → 1-ше прослуховування (gist) → 2-ге: по одному питанню на учня → відповідь Мії | 5 |
| 3 · I DID Care! | сварка Мії й Алекса → micro discovery (3 питання) → правило DO / DOES / DID + base verb → **REPAIR THE CONVERSATION** (1 завдання на учня) → «Friday, 7:15 PM» | 5 |
| 4 · Noah’s Secret | Ной сидить окремо й ділиться почуттями → **WHAT WOULD YOU SAY?** (роль одного з друзів, таймер 0:30, peer question) → голосування A / B / C і реакція героїв | 5 |
| 5 · Friendship Fix | SAVE THE LAST HANGOUT! (3 кроки, правила, прихований приклад) → Solo / Pairs / Teams з ролями, таймер 4:00 → презентації: питання, підхід групи, чек-лист | 7 |
| 6 · The Last Photo | голосування за фінал (прозора підказка) → фінал A / B / C → спалах і полароїд → **A real friend should…** (1 відповідь на учня) | 4 |
| 🎮 Game Zone | Alias (кнопка + шпаргалка на 11 виразів на одному екрані: Study / Challenge / Hint), Kahoot (12 питань для копіювання + поле для посилання), банки додаткових завдань | після уроку |

## Smart task distribution

- Кількість обов'язкових завдань = **присутні учні × раунди** (лексика 2 раунди, інше — 1).
- Наступне завдання отримує учень із найменшою кількістю відповідей у цій активності, потім — за весь урок; складність завдань вирівнюється, тож найважчі не дістаються одній людині.
- **👥 Crew** (або перший екран уроку): додати / перейменувати / позначити відсутнім / прибрати учня — у будь-який момент. Виконані відповіді ніколи не стираються; якщо ціль змінилась, на екрані завдання це видно (наприклад: «Target adjusted to 11: N×R = 10 + 1 turn already done by a student who is now absent»).
- Додаткові завдання («+ Extra challenge») не рахуються в обов'язкові.
- Ролі для читання реплік (🎙 чип біля репліки) розподіляються окремо й так само рівномірно; клік по чипу — віддати репліку іншому учневі.

## Як провести

1. Відкрийте урок із платформи, у першому екрані впишіть імена й позначте присутніх.
2. Для Zoom два варіанти:
   - **📺 Focus** (F) — повний екран, вчительські кнопки й нотатки сховано;
   - **🖥 Audience** — окреме чисте вікно уроку. Діліться в Zoom саме ним (з «Share sound» для голосового), а собі лишіть **🧑‍🏫 Workspace** (W): нотатки, відповіді, CCQ / ICQ, переклад, присутність, розподіл завдань, таймери.
3. Клавіші: → / пробіл — далі, ← — назад, **R** — відповідь, **H** — сховати, **I** — підказка, **D** — завдання виконано (наступний учень), N — сцени, C — Crew, G — Game Zone.
4. **⚡ Quick** — пропускає необов'язкове (прогноз, peer questions, таймер breakout 3:00), але жодне обов'язкове завдання учня не зникає.
5. Годинник уроку ⏱ угорі стартує з кнопки START THE STORY; урок ніколи не перемикається сам, коли закінчився таймер.
6. Усе зберігається в браузері: перезавантаження сторінки чи перехід у Game Zone нічого не скидає. Повне скидання — 🗺 Scenes → Restart.

## Live-режим (необов'язковий)

**📡 Live → Start live room** — код, посилання і QR. Учні входять з іменем, як у списку Crew (лише ім'я). Телефон показує, чия зараз черга («It’s YOUR turn!»), голосування за рішення про Ноя та за фінал, ідеї для прогнозу, а під час breakout — свою команду й роль. Відповіді доходять на телефони лише після Reveal; повідомлення вчителя підписані ключем, тож учень не може керувати уроком. Без Live урок повністю працює на спільному екрані.
