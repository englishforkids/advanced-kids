# Lesson 17 — Who’s Controlling the Scroll? (Vocabulary)

Мія хотіла подивитися «ще одне відео» перед сном — і зникло 54 хвилини. Учні — **Control Team**:
шукають п’ятьох «підозрюваних» у телефоні Мії (🔔 Notifications · ▶️ Autoplay · 📢 Ads · ❤️ Likes · 🌀 The Feed)
і допомагають їй повернути контроль. Граматики немає.

Головна думка уроку: **The goal isn’t to stop scrolling. The goal is to decide when YOU want to scroll.**

  Фон теж змінюється: від хаосу сповіщень до спокійних ✨🌙.

## Як працює нова лексика

Завжди однаково: **Read → Guess → Match → Check**.
1. Учні читають коротку історію; нові вирази підсвічені рожевим.
2. Значень заздалегідь **немає** — клік по рожевому виразу показує «🔒 Guess first!».
3. Зіставлення: клікніть вираз, потім значення (наступний вираз вибирається сам). **Check** перевіряє:
   неправильні пари трусяться червоним. **Fill one pair** (💡) підказує одну пару, **Show answer** — усі.
4. Після перевірки з’являються українські переклади, а кожен вираз (і в історії, і в списку) відкриває
   **картку**: просте пояснення англійською, переклад, ще один приклад.
5. Одне коротке контрольне питання — і далі історія.

Вирази повторюються пізніше: в аудіо Лео, у питаннях для розмови, у breakout і на фінальних чіпах.

## Як провести урок

1. Відкрийте урок із платформи й поділіться екраном у Zoom. **Під час аудіо ввімкніть «Share sound».**
2. **Continue** (→ / пробіл) — наступний кадр історії або наступний екран. **Back** (←) — назад.
3. **Help** (H) і **Show answer** (A) унизу. Нічого не відкривається саме.
4. **⏭ Skip extra** з’являється біля завдань з позначкою *EXTRA — SKIP IF NEEDED*.
5. **🧑‍🏫 Teacher** (T): що сказати, нотатки й відповіді, **🇺🇦 переклади тільки для вчителя**, годинник уроку
   (план vs факт), кнопки *Reset this task*, *Mark scene done*, *Play listening*, *Breakout task*, *Start timer*,
   *Live room*, перемикачі Core route / переклади на екрані / звуки, перехід до будь-якої сцени, **Reset lesson**.
6. **🗺️ Scenes** (M) — меню всіх екранів.
7. Голосування: клацайте варіанти, щоб рахувати руки, — або учні голосують з телефонів (Live).
8. Сцена 14: **📋 Copy for Zoom chat** копіює всю місію для кімнат. Таймер працює й на інших екранах (⏱ угорі).
9. Сцена 15: клацніть кнопку, яку обрав клас (або **Use class vote**). CHECK IT NOW → жартівливе
   «Nice try…» і **Choose again**.

Усе зберігається в браузері: оновлення сторінки повертає на той самий екран. Для нової групи — **Reset lesson**.

## Live Student Mode (необов’язково)

**📡 Live → Start live room.** Учні заходять за QR-кодом, посиланням `…/lesson-17.html?room=1234&role=student`
або через `…/lesson-17.html?join` + 4-значний код. Лише псевдонім, жодних акаунтів.

На телефоні учень бачить поточну сцену й шкалу контролю та може:
голосувати (опитування й рішення історії), **зіставляти** вирази (A/B/C/D), обирати кілька відповідей (listening),
надсилати короткі відповіді (прогноз, speaking), писати **Survival Kit** команди у спільних полях (назва + 3 правила),
реагувати 🛡️💡😂 на презентації.

Керує лише вчитель: учні не можуть перемкнути сцену, а правильні відповіді приходять на телефон тільки після
перевірки на головному екрані. Панель 📡 унизу праворуч показує, хто приєднався, голоси, відсоток правильних
пар у зіставленні (видно лише вчителю) і текстові відповіді (кнопка **Show** виводить відповідь на екран).

Бекенд — той самий Supabase Realtime (broadcast + presence), що в уроках 5, 13–16; ключі вже вписані в
`window.LESSON_CONFIG`. Таблиці не потрібні. Без зв’язку з Supabase панель показує «this browser only».

> Безкоштовний Supabase засинає після 7 днів без активності — перевірте кімнату напередодні уроку.
