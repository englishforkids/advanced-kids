# Lesson 24 — The New Kid 🎒

Unit 3 · **лексичний урок «Belonging & Being Left Out»**: 12 виразів, без окремої граматики · основний урок 25–30 хв + Game Zone.

Ітан, 15, — новенький у школі. Мія знайомить його з Джеєм і Софі й кличе в суботу до скейт-парку, але час і місце так ніхто й не надсилає. У суботу Ітан бачить фото друзів без себе, Софі читає його повідомлення й мовчить… У понеділок з’ясовується: Мія думала, що напише Джей, Джей думав, що Мія вже написала, а Софі допомагала братові й забула відповісти. Місія учнів — **допомогти Ітану знайти «своїх людей», не змінюючи себе**.

```
lessons/lesson-24/
├── lesson-24.html        увесь урок (один файл, vanilla JS, без збірки)
├── img/cast/             ethan · mia · jay · sophie · kai (Ітан і Кай вирізані з нових фото сцен)
├── img/scenes/           17 фото-кадрів уроку (8:3, Instagram-пост — 4:3)
```

Кадри з героями — фото з `img/scenes/`, підключені в `SCENE_PHOTOS`. Ефекти на фото (повільний «Ken Burns», світловий відблиск при появі, мерехтіння ламп і гірлянд, сонце, пилинки, «лайк» на Instagram-пості, думки-бульбашки Ітана) задані в `PHOTO_FX` (файл, розділ «3 · art»); прибрати ефект — видалити рядок. Якщо фото не завантажиться, урок показує намальовану кодом сцену. При «reduced motion» анімації вимикаються.

## Smart task distribution

- Обов’язкові завдання = **присутні учні × раунди**. 5 учнів: лексика 10, читання 5, Fact/Assumption 5, мовлення 5, рефлексія 5.
- Наступне завдання отримує учень із найменшою кількістю відповідей у цьому блоці, потім — за весь урок; складність вирівнюється.
- Читання й мовлення прив’язані до історії: обов’язкові питання розподіляються по частинах, що ще попереду. Якщо учнів менше 5 — деякі частини мають «Open question — anyone», а ситуацію вирішує весь клас голосуванням; якщо більше — з’являються follow-up / додаткові питання для решти. Читання вголос (🎙) рахується окремо.
- **👥 Class** (або перший екран) — будь-коли: додати учня, що запізнився, перейменувати, позначити відсутнім, прибрати, повернути. Виконані відповіді ніколи не стираються; якщо ціль змінилась, під карткою видно, чому (наприклад, «Target adjusted to 11…»).
- Панель **WHO’S NEXT?** під кожним завданням: хто скільки відповів і хто наступний. Кнопки: ✓ Mark completed, 🤝 With help, ↷ Next student, ⤼ Skip (черга учня зберігається), список — передати іншому, ↶ Undo, + Optional extra (не рахується).
- Відповідь ніколи не зараховується автоматично — лише ваше «Mark completed».

## Як провести

1. Відкрийте урок з платформи → перший екран: кількість учнів, імена, раунди → START LESSON.
2. Для Zoom: **📺 Focus** (F) — повний екран без учительських кнопок, або **🖥 Audience** — окреме чисте вікно, яким ви ділитесь, а собі лишаєте **🧑‍🏫 Notes** (W): нотатки українською, відповіді, CCQ / ICQ, переклад, розподіл завдань, таймери.
3. Клавіші: → / пробіл — далі, ← — назад, **R** — відповідь, **H** — сховати, **I** — підказка, **D** — завдання виконано, N — сцени, C — клас, G — Game Zone.
4. **⚡ Quick** ховає необов’язкові follow-up і peer questions; жодне обов’язкове завдання учня не зникає.
5. Усе зберігається в браузері: перезавантаження сторінки нічого не скидає. Повне скидання — 🗺 Scenes → Restart.

## Live-режим (необов’язковий)

**📡 Live → Start live room** — код, посилання і QR. Учні входять з тим самим ім’ям, що у списку класу. Телефон показує, чия черга, голосування (перший крок, рішення класу, Kahoot, нагороди), команду й роль у breakout і дає заповнювати картку своєї команди. Відповіді доходять на телефони лише після Reveal; повідомлення вчителя підписані ключем, тож учень не може перемикати сцени, відкривати відповіді чи змінювати присутність. Якщо Supabase недоступний, сторінка чесно пише «LOCAL DEMO — this browser only». Без Live урок повністю працює на спільному екрані.
