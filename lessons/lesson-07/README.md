# Lesson 7 — Voices in My Head · The Headspace Chat: Who Gets the Mic?

Мія завтра показує свій комікс на шкільному творчому заході, але один коментар («That’s a bit weird») запускає її внутрішній чат.
Учні знайомляться з 12 виразами про внутрішній діалог, читають історію Мії, обирають, якому «голосу» віддати мікрофон,
і в breakout rooms допомагають героям замінити негативну думку на доброзичливу й реалістичну.
Граматики на уроці немає.

```

├── img/mia.webp     Мія (те саме фото, що в уроках 15–16)
├── img/leo.webp     Лео (те саме фото, що в уроках 15–16)
├── img/alex.webp    Алекс — команда 2 (фото з уроку 13)
```

Комікс Мії про робота Bolt, «голоси» (Inner Critic / Hype Voice / Helpful Coach) та іконки — вбудовані у файл (SVG), окремих картинок не потребують.

## Маршрут (≈ 30 хв активностей + пояснення, переходи й презентації = 60 хв)

| Сцена | Що відбувається | хв |
|---|---|---|
| 1 · New Message 📩 | повідомлення й комікс Мії → місія → що таке «voices» → warm-up 1, 2 · 3 *(optional)* | 3 |
| 2 · Previously… ⏪ | 6 старих слів (stand out, fit in, label, quirky, peer pressure, fake it) у 6 повідомленнях | 2 |
| 3 · Inside the Chat 💭 | 6 карток: inner critic … empowering → Name the Thought (Quick: № 1 і № 3) | 4 |
| 4 · Change the Chat 🔄 | 6 карток: mental reset … glow-up → Choose Mia’s Next Move → «A reframe should be kind and believable» | 4 |
| 5 · Read Mia’s Story 📖 | прогноз → 4 абзаци (жовті слова клікабельні) → Fact / Prediction / Opinion → 2 питання · 1 *(optional)* | 6 |
| 6 · Who Gets the Mic? 🎤 | 3 голоси → пояснення за кнопкою → Speak up (Hint, Sample answers) · 3 питання *(optional)* | 3 |
| 7 · Help Your Character 🛟 | інструкція → приклад (Nina) → 3 перевірочні питання → картки команд Leo / Alex / Sam → кімнати 6 хв → презентації | 6 + 45–60 с на команду |
| 8 · Final Message 💌 | фінальне повідомлення Мії → exit ticket → 4 кроки підсумку → Vocabulary Recap | 2 |

## Як провести урок

1. Відкрийте урок із платформи й поділіться екраном у Zoom.
2. **Continue** (→ / пробіл) — далі; на довгих екранах вона спершу відкриває наступну картку / абзац. **Back** (←) — назад. Continue ніколи не блокується.
3. **UA** (U) угорі вмикає всі переклади на екрані; маленькі кнопки **UA** — переклад одного речення. За замовчуванням переклади, відповіді й зразки сховані.
4. Вправи: учні кажуть відповідь — ви обираєте її (меню у пропуску, кнопки-варіанти). **Check** показує ✓ / ✗ і коротке пояснення англійською, **Try again** очищає, **Show answers** відкриває ключ.
5. **🧭 Full / Quick** ховає всі optional-завдання. **⏭ Skip optional** унизу пропускає поточне optional-завдання.
6. **🧑‍🏫 Teacher Notes** (T): мета, час, що сказати англійською, пояснення українською, ключі, можливі відповіді, що можна пропустити; вкладки **General** і **Tools** (маршрут, перехід до сцени, нотатки в окремому вікні, Reset). Панель не захищена паролем.
7. **⏱ Timer** запускається тільки вручну, без звуку. **🗺️ Scenes** (M) — меню всіх екранів, Vocabulary Recap і **Reset lesson** (з підтвердженням).

Поточна сцена, відповіді та чернетки команд зберігаються в браузері — оновлення сторінки повертає на той самий екран. Для нової групи — **Reset lesson**.

## Breakout rooms без Live-режиму

- Кожна команда має окрему картку, яка відкривається без попередніх сцен:
  `…/lesson-07.html?team=leo`, `?team=alex`, `?team=sam`.
- На екрані «Team cards»: **🔗 Copy link** або **📋 Copy team task** (ситуація, інструкція, шаблон, підказки, ролі) → вставте в чат кімнати.
- На картці: готова негативна думка, лише два поля (Better thought / Next action), підказки й word bank, таймер 6:00 / 4:00, **Presentation view** великим шрифтом.
- **Без Live-режиму синхронізації між пристроями немає**: команда обговорює відповідь у Zoom, один спікер записує речення на своєму пристрої (чернетка зберігається на ньому) або в чаті кімнати. На кроці «Presentations» учитель може вставити текст у поля й відкрити Presentation view.

## Live Student Mode (необов’язково)

**📡 Live → Create session.** Учні заходять за QR-кодом, посиланням `…/lesson-07.html?room=1234&role=student` або через `…/lesson-07.html?join` + код і нікнейм.
На телефоні учень голосує (warm-up, прогноз, Who Gets the Mic?), надсилає коротку відповідь (warm-up 2, Speak up, exit ticket), пише в **одну спільну картку команди** (два поля, усі учасники бачать той самий текст) і надсилає реакції Helpful reframe / Useful action / Great teamwork.
Сцену й таймер контролює лише вчитель. Голоси з’являються на головному екрані тільки після **📊 Show class results**; відповіді — після **Show** у панелі кімнати.
Панель кімнати (внизу праворуч) згорнута, бо її видно на спільному екрані. **End session** завершує кімнату на всіх телефонах.

Використовується **Supabase Realtime** (broadcast + presence) — той самий проєкт, що в уроках 5, 13–16; ключі вже вписані на початку `lesson-07.html` у `window.LESSON_CONFIG`, таблиці не потрібні.
Якщо сервер недоступний, кімната просто не відкривається (без імітації) — урок через демонстрацію екрана працює повністю.

> Безкоштовний Supabase засинає після 7 днів без активності — перевірте кімнату напередодні уроку.

Зберігати відповіді в базі (опційно): `SAVE_ANSWERS: true` і додайте `'lesson07-voices'` до списку в політиці `lesson_answers` (див. README уроку 16).
