# Lesson 26 — Backstage Pass: Save the Show 🎤

Unit 3 · **урок повторення (Lessons 24–25)**: 12 виразів про дружбу й належність + relative clauses with prepositions · ≈40 хв разом з Alias.

Учні стають командою за лаштунками фестивалю City Beats. Отримують пропуск, проходять «саундчек» (швидка перевірка слів + Alias), а потім зникає головний співак Лео. Учні читають історію в трьох частинах, збирають підказки на Clue Board, виправляють записки Майї (*the room Leo is practising **in***), знаходять Лео в репетиційній з волонтером Семом, обговорюють, чи має Сем вийти на сцену, і голосують. Після breakout-місії «Save the Show» звучить один із трьох фіналів — той, який обрав клас.

├── lesson-26.html     увесь урок (один файл, vanilla JS, без збірки — рушій уроків 5–25)

## Smart task distribution

- 5 практичних блоків: розминка, слова, читання, граматика, мовлення. Обов’язкових завдань у кожному = **присутні учні × R** (R = 1 за замовчуванням). 5 учнів → 5 + 5 + 5 + 5 + 5; 3 учні → по 3; 8 учнів → по 8 (додаткові питання з того самого матеріалу).
- Перший учень у кожному блоці різний (ротація), той самий учень не отримує два завдання поспіль.
- Зміна присутності будь-коли (👥 Class): виконане не зникає, перераховується лише решта. Завершений блок сам не відкривається — під ним «Reopen for them» або «+ Optional extra question».
- Читання вголос (чипи 🎙) і відповіді на прогнози (🗣) розподіляються окремо й так само рівномірно.
- Breakout — командна робота, ходи не рахуються. Alias — роль пояснювача по колу.

## Як провести

1. Відкрийте урок із платформи → кількість учнів → START LESSON.
2. Zoom: **📺 Focus** (F) — повний екран без учительських кнопок, або **🖥 Audience** — окреме чисте вікно для демонстрації.
3. Клавіші: → / пробіл — далі, ← — назад, **R** — відповідь (у граматиці друге R — пояснення), **H** — сховати, **I** — підказка, **D** — завдання виконано, N — сцени, C — клас, W — нотатки, G — Game Zone.
4. **⚡ Quick** ховає необов’язкове (додаткові питання, peer questions); жодне обов’язкове завдання не зникає.
5. Усе зберігається в браузері: перезавантаження нічого не скидає. Повне скидання — 🗺 Scenes → Restart (з підтвердженням).

## Live-режим (необов’язковий)

**📡 Live → Start live room** — код, посилання і QR (той самий Supabase, що й в інших уроках, лише Realtime). Телефони показують: чия черга (відповідь — лише після Reveal), голосування «What should happen next?» (один голос на людину; можна змінити, доки опитування відкрите), свою команду, роль і картку плану в breakout, Quick Challenge з балами. Повідомлення вчителя підписані ключем — учень не може перемикати сцени чи відкривати відповіді. Без Supabase сторінка чесно пише «this browser only».
