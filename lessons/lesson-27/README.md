# Lesson 27 — The Group Project Disaster 🤝

Unit 3 · **Conflict Isn’t the End** · лексичний урок (10 виразів про конфлікт і примирення, без граматики) · основний урок **28 хв** + Game Zone 10–15 хв.

Четверо друзів два тижні робили шкільний проєкт. На презентації вчителька хвалить лише Лео — хоча він пропустив половину зустрічей. Майя зривається в груповому чаті, Лео виходить із чату. Потім обидва надсилають Ітану голосові — і з’ясовується, що в Лео бабуся була в лікарні. Учні допомагають друзям вислухати одне одного, визнати помилки, встановити межі й вирішити, що далі. Мораль — **не** «друзі завжди мусять пробачати»: голосування за фінал має три рівноправні варіанти.

## Smart task distribution

- Чотири індивідуальні блоки: Reading/Hook, Vocabulary, Listening, Speaking. Обов’язкових завдань у кожному = **присутні учні × R** (R = 1). 5 учнів → 5 + 5 + 5 + 5. Учнів 1–8.
- Перші 5 завдань у кожному блоці — точно з плану; 6–8 — запасні з того самого сюжету.
- Наступний — учень із найменшою кількістю відповідей; той самий учень не отримує два завдання поспіль.
- Під завданням: ✓ Mark completed · 🤝 With help · ⤼ Skip (= Needs another try, черга зберігається) · ↷ Next student · ↶ Undo.
- Зміна присутності будь-коли (👥 Class): виконане не зникає, перераховується лише решта.
- Breakout: 3 → одна команда, 4 → 2 пари, 5 → Team A (Maya, Leo) + Team B (Maya, Leo, Ethan); ⇄ / 🔁 — ручні зміни.

## Як провести

1. Відкрийте урок із платформи → кількість учнів → START LESSON.
2. Zoom: **📺 Focus** (F) або **🖥 Audience** (окреме чисте вікно). **Share sound** — обов’язково для Епізоду 3.
3. Клавіші: → / пробіл — далі, ← — назад, **R** — відповідь, **H** — сховати, **I** — підказка, **D** — завдання виконано, **P** — play/pause голосового, N — епізоди, C — клас, W — нотатки, G — Game Zone.
4. Усе зберігається в браузері: перезавантаження нічого не скидає. Повне скидання — 🗺 Episodes → Restart (з підтвердженням).

## Live-режим (необов’язковий)

**📡 Live → Start live room** — код, посилання, QR (той самий Supabase Realtime, що й в інших уроках). Телефони: опитування, голос за фінал (результати приховані до закриття), «Your turn!» — у словниковому й мовленнєвому блоках учень може обрати варіант зі свого телефона, свою команду й роль у breakout. Повідомлення вчителя підписані ключем. Без Supabase урок працює в **Local Classroom Mode** і чесно це показує — жодних «фейкових» учнів чи голосів.

## Голоси й картинки
