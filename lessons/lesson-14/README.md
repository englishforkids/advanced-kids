# Lesson 14 · Likes Don’t Equal Love — Advanced Kids 2.0

Student-led, story-driven, practice-first. Core Lesson ≈ 27 min + separate Game Zone.

## Episodes (Core)
1. The Viral Post — 3 min · post → comments → Mia's message → class vote → 5 individual prompts
2. Decode the Reactions — 7 min · 10 phrase cards (2 per student), Hint / Check / CCQ / Explain to the Team
3. What Really Happened? — 6 min · predict → Leo & Noah dialogue (two voices) → rebuild the story timeline
4. The Decision Feed — 5 min · 5 reactions + peer questions, 30-second timer
5. Breakout Mission — 6 min · Save the Friendship: three-step rescue plan, roles, 2:00 timer, presentation stage
Final — vote A–D with consequences, the responsible ending, reflection cards, Mission Complete

Game Zone: Kahoot (12 questions, copy button) · Alias · Who Said It? · Fix the Comment · Hot Take

## Teacher

- Teacher panel: 🧑‍🏫 button or **T**. Reveal / Hide Answer, Hint, Teacher Note + ICQ, Reset Task, Mark as Complete, Skip Optional, timer.
