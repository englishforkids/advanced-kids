# Lesson 28 — Real Talk: The Friendship Podcast 🎙

Unit 3 · **Cleft Sentences** (It was Oliver who… / What Sam needs is… / All Oliver wants is…) · повторення 10 виразів дружби з уроків 21–27 · основний урок **30 хв** + Game Zone 10–15 хв.

Учні — запрошені гості-експерти підліткового подкасту **REAL TALK**, епізод 28 «What Really Matters?». Ведучі Майя й Лео отримують повідомлення від Сема: найкращий друг розповів його секрет. Потім приходить версія Олівера: він сказав лише одному однокласнику, а той розповів іншим. Учні розбираються в обох сторонах, відкривають, як cleft sentences «підсвічують» головне, виправляють сценарій Лео, відповідають на дзвінки гарячої лінії і записують власний епізод з порадами. Голос класу обирає, яке оновлення надішле Сем.

## Smart task distribution

- П’ять індивідуальних блоків: Vocabulary, Reading, Grammar Round 1, Grammar Round 2, Speaking. Обов’язкових завдань у кожному = **присутні × R** (R = 1). 5 учнів → 5 + 5 + 10 + 5.
- Перші 5 завдань у кожному блоці — точно з плану; 6–8 (у лексиці 6–9) — рівноцінні запасні для більших груп.
- Наступний — учень із найменшою кількістю відповідей; той самий учень не отримує два завдання поспіль (і між блоками).
- Присутність можна змінити будь-коли (👥): виконане зберігається, перераховується лише решта; у робочій панелі видно, як змінилася ціль.
- Раунд 2 граматики можна пропустити цілком (кнопка після Раунду 1 або в 🧑‍🏫 Workspace → Tools) — тоді його завдання не рахуються.
- Peer questions, обговорення й бонус — необов’язкові й не рахуються.

## Як провести

1. Відкрийте урок із платформи → кількість учнів → START LESSON → START EPISODE.
2. Zoom: **📺 Focus** (F) або **🖥 Audience** (окреме чисте вікно, його й показувати).
3. Клавіші: → / пробіл — далі, ← — назад, **R** — показати, **H** — сховати, **I** — підказка, **D** — завдання виконано, **Q** — довідка з граматики, N — сцени, C — клас, W — робоча панель, G — Game Zone.
4. 🔦 у верхній панелі відкриває компактну довідку (IT / WHAT / ALL) поверх будь-якого екрана.
5. Звук (тихі ефекти) вимкнений за замовчуванням: 🔇 угорі, гучність — у Workspace → Tools.
6. Усе зберігається в браузері: оновлення сторінки нічого не скидає. Повне скидання — 🗺 → Restart (з підтвердженням).
