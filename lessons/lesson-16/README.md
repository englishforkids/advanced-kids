## Як провести урок

1. Відкрийте урок із платформи (або `lesson-16.html` напряму) і поділіться екраном у Zoom.
2. **Continue** (→ / пробіл) веде вперед: у сценах 1, 2, 3, 4 і 7 вона відкриває наступне повідомлення / картку / доказ, потім переходить далі. **Back** (←) — назад.
3. **Hint** (H) — стартери речень, український зміст фрази, словничок. **Show answer** (A) — відповідь / приклад. Нічого не відкривається само.
4. **Skip optional** зʼявляється, коли наступне або поточне завдання необовʼязкове. **🧭 Full / Core** угорі ховає всі optional-завдання й вмикає Quick route у сцені 2.
5. **🧑‍🏫 Teacher** (T): що сказати, нотатки українською, відповіді, годинник уроку (запланований час vs фактичний), перемикачі маршруту, перехід до будь-якої сцени, **Reset lesson**.
6. **🗺️ Scenes** (M) — меню всіх екранів; сюди ж вбудована кнопка **Reset lesson** (з підтвердженням).
7. Сцена 6: «📋 Copy for Zoom chat» копіює місію для кімнат → **Start 5:00**. Таймер працює й на інших екранах (⏱ угорі) і дзвонить наприкінці.
8. Презентації: якщо команди писали в чаті Zoom — вставте їхній текст прямо в поля картки команди. Якщо команд більше 4, вмикається «Calm + What if only».

Усе зберігається в браузері: випадкове оновлення сторінки повертає на той самий екран (разом із таймером і відкритою live-кімнатою). Для нової групи — **Reset lesson**.

## Live Student Mode (необовʼязково)

**📡 Live → Start live room.** Учні заходять:

- за QR-кодом або посиланням `…/lesson-16.html?room=1234&role=student` (кнопка «Copy link» → у чат Zoom), або
- за адресою `…/lesson-16.html?join` і вводять 4-значний код кімнати.

Учень вводить лише псевдонім (без прізвища й персональних даних). На телефоні він бачить поточну сцену та:
голосує (лічильники одразу на екрані вчителя), надсилає короткі відповіді (warm-up, питання після читання, пропуски з mixed conditionals, Speak up),
пише командну роботу в **три спільні поля** (усі учасники команди бачать той самий текст), реагує ✅ 💛 🧠 під час презентацій.

Керує лише вчитель: сцену, завдання й таймер надсилає тільки його сторінка; учні не можуть перемкнути сцену чи відкрити відповіді —
правильний варіант приходить на телефон тільки після **Show answer** на головному екрані.
Панель 📡 унизу праворуч показує статус зʼєднання (● live / reconnecting / this browser only), псевдоніми тих, хто підключився,
і відповіді: кнопка **Show** виводить відповідь на екран, у пропусках одразу видно ✓ / ✗.

## Що потребує налаштування бекенду

Live-режим використовує **Supabase Realtime** (broadcast + presence) — той самий проєкт, що в уроках 5, 13–15. Ключі вже вписані
на початку `lesson-16.html` у `window.LESSON_CONFIG`:

| Параметр | Значення |
|---|---|
| `SUPABASE_URL` | `https://yhekszqxheljbxoucalt.supabase.co` |
| `SUPABASE_KEY` | publishable (anon) ключ проєкту |
| `SAVE_ANSWERS` | `false` — відповіді не зберігаються в базі |

Таблиці для live-режиму **не потрібні**. Якщо ключі порожні або Supabase недоступний, панель показує «this browser only» —
тоді кімната працює лише між вкладками одного браузера (для перевірки), а сам урок через демонстрацію екрана працює повністю.

> Безкоштовний Supabase засинає після 7 днів без активності — перевірте кімнату напередодні уроку.

### Зберігати відповіді (опційно)

`SAVE_ANSWERS: true` пише голоси, відповіді й командну роботу в таблицю `lesson_answers`
(схема `lessons/lesson-05/sql/schema.sql`). Політика доступу в цій схемі дозволяє запис лише для уроку 5,
тому один раз виконайте в Supabase → SQL Editor:

```sql
drop policy if exists "anon can insert answers" on public.lesson_answers;
create policy "anon can insert answers"
  on public.lesson_answers for insert to anon
  with check (
    lesson in ('lesson5-inversion','lesson15-mixed','lesson16-hype')
    and length(coalesce(value, '')) <= 500
    and length(coalesce(student_name, '')) <= 40
  );
```
