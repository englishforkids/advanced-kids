## Smart task distribution

- Обов’язкові завдання = **присутні учні × R** у блоках Recall, Reading, Grammar, Speaking (R = 1). Alias — **2 ходи на учня** (`ALIAS_TURNS`). 5 учнів → 5 · 10 · 5 · 5 · 5.
- Читання: питання розподіляються між трьома підказками по колу — 5 учнів → 2 + 2 + 1, 4 → 2 + 1 + 1, 6 → 2 + 2 + 2. Питання завжди лише про вже прочитану частину; для більших груп — рівноцінні резервні питання з тієї самої частини.
- Граматика: 1–5 — з плану, 6–11 — резервні (змішані структури). Мовлення: 1–5 + 3 резервні.
- Присутність змінюється будь-коли (👥 Class або − / + у лобі): виконане не зникає, перераховується лише решта. Наступним відповідає той, у кого найменше ходів. Індикатор на картці: **Student 3 / 5 — Your Turn!**
- ⤼ Skip — учень ще не готовий, черга зберігається. Optional extra — не рахується.

## Як провести

1. Відкрийте урок із платформи → кількість учнів → START LESSON.
2. Zoom: **📺 Focus** (F) — повний екран без учительських кнопок, або **🖥 Audience** — окреме чисте вікно для демонстрації (собі лишаєте нотатки й відповіді).
3. Клавіші: → / пробіл — далі, ← — назад, **R** — показати (у читанні спершу питання, потім відповідь), **H** — сховати, **I** — підказка, **D** — завдання виконано, N — сцени, C — клас, W — нотатки, G — Game Zone, Esc — вийти з Focus.
4. **Alias у Zoom:** слово бачить лише пояснювач. Варіанти: (1) 🖥 Audience / 📺 Focus — учні бачать «🤫 Only … knows the word», ви бачите слово на своєму екрані й 📋 копіюєте в приватний чат Zoom; (2) 📡 Live — слово з’являється на телефоні пояснювача; (3) 👁 Show word on screen — показати всім.
5. Усе зберігається в браузері: перезавантаження нічого не скидає. Повне скидання — 🗺 Scenes → Restart (з підтвердженням).
