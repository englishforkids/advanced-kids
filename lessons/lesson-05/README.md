# Lesson 5 — Inversion for Emphasis

Інтерактивний урок-епізод для живого заняття в Zoom.
**🎬 The Night Everything Went Wrong** · Advanced Kids, 11–15 років · 42 або 56 хвилин.

Учитель веде урок зі свого екрана, учні приєднуються за посиланням з телефонів
і відповідають на запитання, які вчитель відкриває сам.

**Ніколи не працювали з GitHub і Supabase?** Почніть звідси:
[`SETUP.md`](SETUP.md) — інструкція з нуля, крок за кроком.

Повний методичний гайд до самого уроку: [`docs/teacher-guide.pdf`](docs/teacher-guide.pdf)

## 2. Публікація на GitHub Pages

1. Створіть репозиторій, наприклад `lesson5-inversion`.
2. Завантажте в нього вміст цієї папки (`Add file → Upload files`, перетягніть усе разом із папками).
3. **Settings → Pages → Build and deployment**: Source = `Deploy from a branch`,
   Branch = `main`, папка = `/ (root)`. Save.
4. За хвилину-дві сторінка буде тут:
   `https://<ваш-нік>.github.io/lesson5-inversion/`
5. Відкрийте посилання, натисніть **📡 Connect** — і перевірте, що код кімнати з'явився.

Усі шляхи всередині відносні, тому урок працює і в підпапці репозиторію,
і на власному домені, і навіть якщо просто відкрити `index.html` з диска.

> **Оновлення уроку:** просто замініть `index.html` у репозиторії. GitHub Pages
> підхопить зміни за хвилину. Учням може знадобитися оновити сторінку (Ctrl+Shift+R).

## 3. Підключення Supabase

Живі відповіді працюють через **Supabase Realtime (broadcast)**. Таблиці для цього
не потрібні — повідомлення просто пролітають через канал кімнати.

### Крок 1 — взяти адресу і ключ

У панелі Supabase:

- **Settings → Data API → Project URL** — адреса вигляду `https://abcdefghijklm.supabase.co`
- **Settings → API Keys → Publishable key** — рядок вигляду `sb_publishable_…`
  (у старих проєктах замість нього буде **anon** ключ `eyJ…` — він теж підходить)

### Крок 2 — вставити його у файл

На початку `index.html` є єдиний блок, який треба редагувати:

```js
window.LESSON_CONFIG = {
  SUPABASE_URL  : 'https://abcdefghijklm.supabase.co',
  SUPABASE_KEY  : 'sb_publishable_…',
  SAVE_ANSWERS  : false
};
```

Збережіть, залийте на GitHub — і все. Публікований ключ призначений саме для коду
на сторінці: він дає доступ лише до того, що дозволено політиками RLS, а тут не дає
доступу ні до чого.

### Крок 3 — перевірити

**Connect → Start live room.** Статус має стати **live · Supabase**.
Якщо написано *local only (same browser)* — ключа немає або він неправильний.

> **Realtime → Settings → Allow public access** має лишатися увімкненим (значення
> за замовчуванням). Якщо його вимкнути, канали стануть приватними і телефони учнів
> не підключаться.
>
> **Безкоштовний проєкт засинає після 7 днів без активності.** Дані лишаються, але
> кімната не працює, поки не натиснете **Restore project** у панелі Supabase. Якщо між
> уроками буває довша пауза — перевірте кімнату напередодні, а не перед заняттям.

Ключ можна не вшивати у файл, а ввести в самому інтерфейсі — тоді він збережеться
у вашому браузері й поїде всередині посилання для учнів. Це зручно для тесту,
але посилання стане довгим.

## 4. Як учні приєднуються

1. **📡 Connect → Start live room**
2. **Copy** — киньте посилання в чат Zoom. Або покажіть **QR-код** на екрані.
3. Учень відкриває лінк, пише ім'я, тисне **Join** — і з'являється у вашому списку.

Посилання має вигляд:

```
https://<ваш-нік>.github.io/lesson5-inversion/?room=4821&role=student
```

Кімната визначається кодом у посиланні. **New code** створює нову кімнату —
стару вона не чіпає, тому паралельні групи не перетинаються.

### Що бачить учень

| Стан | Екран телефона |
|---|---|
| Активність закрита | «Nothing to tap right now — listen, watch and be ready to speak» |
| Активність відкрита | Питання і великі кнопки відповіді |
| Ви натиснули Show results | Ті самі кнопки + відсотки |
| Завжди | Кнопка **🙋 Raise hand** |

Учень **не може** гортати урок, бачити відповіді, відкривати активність сам
або бачити, хто як проголосував.

### Активності за розділами

| Розділ | Що відкривається на телефонах |
|---|---|
| Chapter 1 | Прогноз: що станеться далі — 4 варіанти |
| Chapter 2 | Normal чи Dramatic |
| Drama toolkit | Який тригер візьмеш сьогодні — 5 варіантів |
| Meaning check | Agree / Disagree |
| Voice message | Головна ідея: A / B / C / D |
| Make it dramatic | Коротка відповідь: своє драматичне речення |
| The Premiere | Голосування за 4 номінації |
| Director's cut | Коротка відповідь: одне речення про себе |

Керування — у доці внизу праворуч: **Open on devices · Close activity · Show results · Clear**.

### Стійкість до збоїв

- Учень оновив сторінку — ім'я та його відповіді збережуться, стан прийде від вас за 20 секунд.
- Зник інтернет — статус стає «reconnecting…», після відновлення все продовжиться.
- Ви перезапустили кімнату — учні підхопляться самі, перезаходити не треба.
- Немає зв'язку зовсім — учень бачить кнопку **Try again**.

## 5. Відповіді після уроку

**Connect → ⬇ Export answers (CSV)** вивантажує все, що зібрала кімната:
голосування, короткі відповіді та голоси за номінації, з іменами учнів.
Файл відкривається в Excel і Google Sheets, кодування UTF-8.

CSV живе лише поки відкрита вкладка. Якщо потрібен постійний архів — див. наступний розділ.

## 6. Опційно: збереження відповідей у базі

За замовчуванням **нічого нікуди не пишеться** — усе живе тільки під час уроку.
Щоб зберігати відповіді:

1. Supabase → **SQL Editor** → виконайте [`sql/schema.sql`](sql/schema.sql).
2. У `index.html` поставте `SAVE_ANSWERS: true`.

Кожне голосування, коротка відповідь і голос за номінацію будуть падати в таблицю
`lesson_answers` з кімнатою, розділом, завданням та іменем учня.

Політика доступу в схемі навмисно вузька: anon-ключ може лише **вставляти** рядки.
Читати їх можна з панелі Supabase або сервісним ключем — учні не бачать
ні чужих відповідей, ні своїх минулих.

Приклад запиту для перегляду:

```sql
select created_at, chapter, task, student_name, value
from lesson_answers
where room = '4821'
order by created_at;
```

## 8. Приватність

- Учні вводять лише ім'я — жодних акаунтів, пошт чи паролів.
- Без `SAVE_ANSWERS` дані не залишають браузери учасників: broadcast нічого не зберігає.
- Прогрес уроку, ім'я учня та його відповіді лежать у `localStorage` відповідного пристрою.
- Код кімнати — це не пароль. Для нової групи натисніть **New code**.
