# Lesson 29 — The Message at Midnight 🌙

Unit 3 · **Revision (Lessons 27–28)** · 10 виразів дружби й конфліктів + **cleft sentences** (It was Leo who… / What upset Maya was… / All Maya wanted was…) · основний урок **29 хв** + Game Zone 10–15 хв.
Концепція **Advanced Kids 2.0 — student-led, story-driven, practice-first**: один екран — одне завдання, учні читають і говорять, учитель лише веде.

Після запису подкасту Лео виклав смішне відео з Майєю, хоча вона просила цього не робити. Він видалив його й вибачився — але продовжував писати. Опівночі Майя відповіла: *«Please stop texting me. I need some space.»* Учні читають чат, слухають обидві сторони, повторюють cleft sentences, обговорюють особисті межі, у breakout складають план відновлення дружби, а клас обирає спільний план.

## Smart task distribution

- Обов’язкових завдань у блоці = **присутні × R** (R = 1). 5 учнів → читання 5 повідомлень, аудіювання 5, граматика 5, мовлення 5, у breakout говорить кожен.
- Перші 5 завдань — точно з плану; 6–10 — рівноцінні запасні (для груп до 10 учнів). Якщо учнів більше 5, у сцені 1 з’являються короткі картки «Previously…», щоб читав кожен.
- Наступний — учень із найменшою кількістю відповідей; блоки починаються з різних учнів (не завжди «перший»).
- Кількість учнів змінюється будь-коли (👥): виконане зберігається, перераховується лише решта.
- ✓ виконано · 🤝 з допомогою · ↷ інший учень · ⤼ пропустити (учень зберігає хід) · 🔀 інше завдання · ↶ скасувати.
- Follow-up, peer-питання, приклади — необов’язкові й не рахуються (ховаються в ⚡ Quick Mode).

## Як провести

1. Відкрийте урок із платформи → кількість учнів (імена — за бажанням) → START LESSON.
2. Zoom: **📺 Focus** (F) або **🖥 Audience** (окреме чисте вікно — його й показувати). Для аудіо — Share sound.
3. Клавіші: → / пробіл — далі, ← — назад, **R** — показати, **H** — сховати, **I** — підказка, **D** — завдання виконано, **Q** — довідка cleft sentences, N — сцени, C — клас, W — нотатки, G — Game Zone.
4. 🧑‍🏫 Workspace — нотатки до кожного екрана (мета, як провести, ключі, типові помилки, переклад українською).
5. Усе зберігається в браузері: оновлення сторінки нічого не скидає. ⟲ Restart this activity — лише поточна активність; ⟲ Restart whole lesson — усе (з підтвердженням).

## Аудіо

`audio/both-sides.mp3` — синтетичні голоси (Kokoro TTS), позначені «AI voice». Свій запис → замініть файл і, якщо зміниться тривалість, оновіть `DIALOGUE.times` (початок кожної репліки в секундах). Немає файлу → браузер читає сценарій сам різними голосами (позначка «browser voice»). Немає й цього → учитель читає транскрипт із 🧑‍🏫 Notes.

## Live-режим (необов’язковий)

**📡 Live → Start live room** — код, посилання, QR (той самий Supabase Realtime, що й в інших уроках). Телефони бачать свою чергу, голосують у сценах 1 і 4, бачать свою команду й частину плану в breakout. Головний екран рухає лише вчитель. Без Supabase урок працює в **Teacher Screen Mode** повністю.
