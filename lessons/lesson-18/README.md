# Lesson 18 — Who Actually Said That? (Reported Speech)

Після уроку 17 Мія нарешті приборкала телефон — але зранку в класному чаті вже 17 повідомлень і чутка про неї.
З кожним переказом історія змінюється. Учні — слідчі: збирають **6 доказів** на дошку, самі відкривають
reported speech і reporting verbs, відновлюють ланцюжок повідомлень, а в breakout rooms працюють як **Rumour Control Unit**.

## Що бачать учні

- Угорі весь урок — **шкала історії з 6 етапів**: 📱 Rumour Detected → 🔎 First Clue → 🧠 Language Decoded →
  📖 Message Chain Rebuilt → 👥 Team Investigation → ✅ Case Closed. Пройдені етапи стають зеленими.
- Кнопка **🗂 Evidence** (клавіша E) — дошка доказів. Докази «вилітають» на екран і падають на дошку:
  слова Лео → голосове Нори → зізнання Макса → що насправді сказала Мія → де історія змінилася → увесь ланцюжок.
- Усе відкривається поступово: повідомлення «друкуються», відповіді — лише після **Check answer**, правила — лише після того, як учні відповіли.
- Тексти для учнів — тільки англійською, рівень B1–B2. Українська — лише в Teacher Mode.

## Як провести урок

1. Відкрийте урок із платформи і поділіться екраном у Zoom.
2. **Continue** (→ / пробіл) — наступне повідомлення / картка / частина; **Back** (←) — назад.
3. **Check answer** (A) — відповідь із короткою причиною простою англійською. **Hint** (H) — підказка або стартери речень.
   Якщо учні відповідають усно — клікайте їхній варіант на екрані, потім Check answer: неправильний вибір підсвітиться червоним.
4. **⏭ Skip optional** зʼявляється, коли наступний екран необовʼязковий.
5. **🧑‍🏫 Teacher** (T): що сказати, нотатки українською, усі відповіді (включно з sample reports для кейсів), годинник уроку,
   **↺ Restart activity** (перезапуск лише поточного завдання), керування таймером, ручне позначення етапів, перехід до будь-якого екрана, **Reset lesson**.
6. **🗺️ Screens** (M) — меню всіх екранів із хвилинами.
7. Голосове Нори читає голос браузера — у Zoom увімкніть **Share sound**. Якщо голосу немає, є транскрипт.
8. Breakout: на екрані Case files оберіть кількість команд (1–4), натисніть **📋 Copy Case … for Zoom chat** і вставте кейс у чат, потім **Start 5:00**.
   Таймер видно й на інших екранах (⏱ угорі), наприкінці дзвінок.
9. Презентації: після кожної команди — **TEAM N COMPLETE**.

## Live-режим для телефонів (необовʼязковий)

**📡 Live → Start live room** — код кімнати, посилання і QR. Учні заходять без акаунта, лише з ніком.
На телефонах: голосування в усіх вправах, короткі відповіді (з автоперевіркою там, де є правильна відповідь),
у breakout — свій кейс і 4 спільні поля для речень команди (їх видно на екрані презентацій), реакції під час виступів, голосування за нагороди.
Вчитель бачить у віконці зліва внизу, скільки учнів відповіли, розподіл відповідей і текстові відповіді (кнопка **Show** виводить відповідь на головний екран).

Supabase — той самий проєкт, що в уроках 5, 13–17 (ключі на початку файлу). Без інтернету / Supabase урок повністю працює через демонстрацію екрана.
